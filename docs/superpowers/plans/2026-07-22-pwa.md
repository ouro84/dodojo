# PWA installable — socle Sprint 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre Dodojo installable en PWA (manifest + icônes + service worker minimal) avec un précache d'app-shell, un cache runtime pour les sprites, un fallback offline léger, un prompt de mise à jour, et un CTA d'installation maison — socle technique pour US-11 (Web Push).

**Architecture:** `app/manifest.ts` (convention native Next.js) pour le manifest + icônes dans `public/icons/` dérivées de `logo.svg`. Service worker via **`@serwist/turbopack`** (pas `@serwist/next` — voir Contrainte ci-dessous) : `app/sw.ts` (source du SW) compilé à la volée par `app/serwist/[path]/route.ts`, précache uniquement l'app-shell (JS/CSS/police/manifest/offline-fallback), cache runtime `CacheFirst` pour les sprites/décors/vfx. Deux petits bouts de logique pure testés en Vitest (résolution de la révision de build, calcul de visibilité du CTA d'installation) ; le reste (registration SW, `beforeinstallprompt`) est du code navigateur non testable unitairement, vérifié manuellement (Lighthouse/DevTools).

**Tech Stack:** Next.js 16.2.10 (App Router, Turbopack), `@serwist/turbopack` + `serwist` + `@serwist/window` + `esbuild`, `sharp` (déjà présent en dépendance transitive, cf. `scripts/copy-boss-sprites.mjs`), Tailwind v4, Vitest.

- TypeScript strict, **aucun `any`** (règle projet CLAUDE.md §Règles de code).
- Commentaires/doc produit en français ; termes techniques en anglais quand c'est l'usage.
- Commits en Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`).
- `CHANGELOG.md` mis à jour sous `[Unreleased]` dans le même commit/PR que la feature (jamais après coup).
- Manuel du Dojo (`content/guide.json`) mis à jour dans la même PR car cette feature est visible utilisateur (installation).
- Pas de test Vitest sur la config Serwist/manifest elle-même (peu de logique pure à isoler) ; pas de test e2e Playwright sur l'installation PWA (hors capacité réaliste de Playwright en CI) — seule la vérification manuelle Lighthouse/DevTools (Tâche 9) fait foi avant de considérer la US terminée.

```js
// Décline public/icons/logo-source.svg en icônes PWA :
// - "any" (192/512, fond transparent) — icône standard du manifest.
// - "maskable" (192/512, fond plein --color-bg) — respecte la zone de
//   sécurité du crop adaptatif Android (spec maskable icons).
// - apple-icon (180x180, fond plein) — Next.js sert automatiquement
//   <link rel="apple-touch-icon"> depuis app/apple-icon.png ; iOS
//   recommande un fond opaque (pas de transparence) pour cette icône.
// Pas de vraie déclinaison claire/sombre du logo lui-même : l'app n'a
// qu'un seul thème (sombre, cf. app/globals.css --color-bg). La passe
// d'identité visuelle multi-thème est hors scope (issue #51).
// Usage : npm run generate:icons
import sharp from "sharp";
import { promises as fs } from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "..");
const SOURCE_SVG = path.join(ROOT, "public", "icons", "logo-source.svg");
const ICONS_DIR = path.join(ROOT, "public", "icons");

// Fond sombre de l'app (--color-bg dans app/globals.css,
// oklch(0.14 0.015 25) converti en sRGB) — fond plein des icônes maskable.
const BRAND_BG = "#0f0706";

// Zone de sécurité maskable : le contenu doit tenir dans un cercle centré
// de 80% du côté (spec Android adaptive icon). On tasse le logo à 60% du
// côté pour garder de la marge, la silhouette de flamme débordant jusqu'aux
// bords de son propre viewBox.
const MASKABLE_CONTENT_RATIO = 0.6;

async function renderAnyIcon(svgBuffer, size) {
  return sharp(svgBuffer)
    .resize(size, size, { fit: "contain", background: { r: 0, g: 0, b: 0, alpha: 0 } })
    .png()
    .toBuffer();
}

async function renderMaskableIcon(svgBuffer, size) {
  const contentSize = Math.round(size * MASKABLE_CONTENT_RATIO);
  const content = await sharp(svgBuffer)
    .resize(contentSize, contentSize, { fit: "contain", background: { r: 0, g: 0, b: 0, alpha: 0 } })
    .png()
    .toBuffer();
  return sharp({
    create: { width: size, height: size, channels: 4, background: BRAND_BG },
  })
    .composite([{ input: content, gravity: "center" }])
    .png()
    .toBuffer();
}

async function main() {
  const svgBuffer = await fs.readFile(SOURCE_SVG);

  const any192 = await renderAnyIcon(svgBuffer, 192);
  const any512 = await renderAnyIcon(svgBuffer, 512);
  const maskable192 = await renderMaskableIcon(svgBuffer, 192);
  const maskable512 = await renderMaskableIcon(svgBuffer, 512);
  const appleIcon = await renderMaskableIcon(svgBuffer, 180);

  await fs.writeFile(path.join(ICONS_DIR, "icon-192.png"), any192);
  await fs.writeFile(path.join(ICONS_DIR, "icon-512.png"), any512);
  await fs.writeFile(path.join(ICONS_DIR, "icon-maskable-192.png"), maskable192);
  await fs.writeFile(path.join(ICONS_DIR, "icon-maskable-512.png"), maskable512);
  await fs.writeFile(path.join(ROOT, "app", "apple-icon.png"), appleIcon);

  console.log("Icônes PWA générées dans public/icons/ + app/apple-icon.png");
}

main().catch((error) => {
  console.error(error);
  process.exit(1);
});
```

```ts
// Dérive un identifiant de build stable pour invalider le precache du
// service worker à chaque déploiement Vercel (main se déploie
// automatiquement à chaque merge, cf. CLAUDE.md). Priorité : SHA fourni par
// Vercel > `git rev-parse HEAD` en local > UUID aléatoire en dernier
// recours (jamais bloquant pour le build).
export function resolveBuildRevision(
  vercelCommitSha: string | undefined,
  resolveGitSha: () => string | null,
): string {
  if (vercelCommitSha) return vercelCommitSha;
  const fromGit = resolveGitSha();
  if (fromGit) return fromGit;
  return crypto.randomUUID();
}
```

- [ ] **Step 5: Créer la source du service worker**

Create `app/sw.ts`:

```ts
/// <reference lib="esnext" />
/// <reference lib="webworker" />
import { CacheFirst, ExpirationPlugin, Serwist } from "serwist";
import type { PrecacheEntry, SerwistGlobalConfig } from "serwist";

declare global {
  interface WorkerGlobalScope extends SerwistGlobalConfig {
    __SW_MANIFEST: (PrecacheEntry | string)[] | undefined;
  }
}

declare const self: ServiceWorkerGlobalScope;

// Chemins publics dont les images sont mises en cache runtime À LA DEMANDE
// (jamais précachées en bloc — 12 boss × dizaines de frames, l'utilisateur
// ne verra jamais la plupart des boss, cf.
// docs/superpowers/specs/2026-07-22-pwa-design.md) : sprites de boss/héros,
// décors, effets visuels.
const RUNTIME_CACHED_IMAGE_PREFIXES = ["/sprites/", "/backgrounds/", "/vfx/"];

const serwist = new Serwist({
  // self.__SW_MANIFEST est injecté par app/serwist/[path]/route.ts : les
  // chunks JS/CSS du build Next.js (hashés, donc déjà versionnés) +
  // additionalPrecacheEntries (police, manifest, page offline — voir route.ts).
  precacheEntries: self.__SW_MANIFEST,
  skipWaiting: true,
  clientsClaim: true,
  navigationPreload: true,
  runtimeCaching: [
    {
      matcher({ request }) {
        if (request.destination !== "image") return false;
        const { pathname } = new URL(request.url);
        return RUNTIME_CACHED_IMAGE_PREFIXES.some((prefix) => pathname.startsWith(prefix));
      },
      handler: new CacheFirst({
        cacheName: "dodojo-sprites",
        plugins: [
          new ExpirationPlugin({
            maxEntries: 250,
            maxAgeSeconds: 60 * 60 * 24 * 90, // 90 jours
          }),
        ],
      }),
    },
  ],
  fallbacks: {
    entries: [
      {
        url: "/offline",
        matcher({ request }) {
          return request.destination === "document";
        },
      },
    ],
  },
});

serwist.addEventListeners();
```

// Un identifiant par build (SHA Vercel en prod, SHA git en local) partagé

    useNativeEsbuild: true,
    additionalPrecacheEntries: [

      { url: "/fonts/boldpixels.woff2", revision },

- [ ] **Step 1: Store client (registration + détection "waiting")**

Create `lib/pwa/update-prompt-client.ts`:

```ts
import { Serwist } from "@serwist/window";

// Singleton module : une seule registration par onglet, peu importe combien
// de composants montent usePwaUpdatePrompt.
let serwist: Serwist | null = null;
let updateAvailable = false;
const listeners = new Set<() => void>();

function emit(): void {
  for (const listener of listeners) listener();
}

// Enregistré uniquement en production : en dev, un SW qui cache des chunks
// JS interférerait avec le Fast Refresh de Next.js.
export function initUpdatePrompt(): void {
  if (serwist || typeof window === "undefined") return;
  if (!("serviceWorker" in navigator)) return;
  if (process.env.NODE_ENV !== "production") return;

  serwist = new Serwist("/serwist/sw.js", { scope: "/" });

  serwist.addEventListener("waiting", () => {
    updateAvailable = true;
    emit();
  });

  serwist.addEventListener("controlling", () => {
    window.location.reload();
  });

  void serwist.register();
}

export function subscribeUpdatePrompt(listener: () => void): () => void {
  listeners.add(listener);
  return () => listeners.delete(listener);
}

export function getUpdatePromptSnapshot(): boolean {
  return updateAvailable;
}

// Dit au SW en attente d'activer immédiatement (self.skipWaiting()) ; le
// listener "controlling" ci-dessus recharge la page une fois qu'il a pris
// le contrôle.
export function reloadForUpdate(): void {
  serwist?.messageSkipWaiting();
}
```

- [ ] **Step 6: Store effectful (capture des évènements navigateur)**

Create `lib/pwa/install-prompt-client.ts`:

```ts
import {
  canInstall as canInstallPure,
  initialInstallPromptState,
  type InstallPromptState,
} from "./install-prompt-store";

let state: InstallPromptState = initialInstallPromptState;
const listeners = new Set<() => void>();
let initialized = false;

function emit(): void {
  for (const listener of listeners) listener();
}

function detectStandalone(): boolean {
  if (typeof window === "undefined") return false;
  const mql = window.matchMedia?.("(display-mode: standalone)");
  return Boolean(mql?.matches) || window.navigator.standalone === true;
}

// Idempotent : appelable depuis plusieurs montages, n'attache les listeners
// qu'une fois. Doit être appelé le plus tôt possible (layout racine) car
// `beforeinstallprompt` ne se rejoue pas s'il est manqué.
export function initInstallPromptCapture(): void {
  if (initialized || typeof window === "undefined") return;
  initialized = true;
  state = { ...state, standalone: detectStandalone() };

  window.addEventListener("beforeinstallprompt", (event) => {
    event.preventDefault();
    state = { ...state, deferredPrompt: event, installed: false };
    emit();
  });

  window.addEventListener("appinstalled", () => {
    state = { ...state, deferredPrompt: null, installed: true };
    emit();
  });
}

export function subscribeInstallPrompt(listener: () => void): () => void {
  listeners.add(listener);
  return () => listeners.delete(listener);
}

export function getInstallPromptSnapshot(): InstallPromptState {
  return state;
}

export { canInstallPure as canInstall };

export async function promptInstall(): Promise<void> {
  const prompt = state.deferredPrompt;
  if (!prompt) return;
  await prompt.prompt();
  await prompt.userChoice;
  state = { ...state, deferredPrompt: null };
  emit();
}
```
